# Phase 07 — QA, Performance, Packaging

## Steps
1. Execute complete gate checklist and testing plan, log actual commands and environment.
2. Balance all levels: novice success on level 1, meaningful risks on level 5. Fix exploits, repeated terminal events, stuck inputs.
3. Clean art hierarchy, update Vietnamese copy, polish animation/alert feedback, sound/visual accessibility.
4. Profile/reduce expensive draw, asset loads, allocations; test rapid retry/background/resume.
5. Build APK debug (optionally release after signing instructions), generate docs for Android install, screenshots and known bugs.
6. Update `docs/PROGRESS.md` to reflect actual proof; no false completion.

## Done when
- [ ] All gate items have traceable proof or documented blockers.
- [ ] App runs 5 levels on Android test target, except explicitly documented unsupported environment.
- [ ] Handoff contains exact run commands, dependency versions and limitations.
